## **THE COMPLETE WORKFLOW CHAIN**

```
INSURED → INSURER → HR MANAGER → ADJUSTER → BACK TO INSURER → INSURED
```

### **Step-by-Step Process:**

1. **Insured Person** files a claim (water damage, fire, etc.)
2. **Insurer** receives claim, reviews it, sets priority
3. **Insurer** requests adjuster from **HR Manager**
4. **HR Manager** assigns available adjuster based on:
   - Location (who's closest?)
   - Workload (who has capacity?)
   - Availability (who's not on leave?)
   - Expertise (who handles fire damage?)
5. **Adjuster** gets notification, visits site, completes inspection
6. **Adjuster** submits report to **Insurer**
7. **Insurer** approves payment
8. **Insured** gets paid and notified

## **🗺️ HR MAP VIEW - DETAILED FEATURES**

### **What HR Sees on the Map:**

**1. ADJUSTER LOCATION MARKERS**
- **Green marker** = Available, no current assignment
- **Blue marker** = On the way to assignment
- **Yellow marker** = Currently at claim site (checked in)
- **Orange marker** = Busy, but finishing soon
- **Red marker** = Overloaded (too many claims)
- **Gray marker** = Off duty / On leave

**2. CLAIM LOCATION MARKERS**
- **Unassigned claims** = Pulsing red dots
- **Assigned claims** = Connected to adjuster with line
- **Completed claims** = Green checkmark icons

**3. TERRITORY BOUNDARIES**
- Colored zones on map (North, South, East, West)
- Each adjuster assigned to specific zones
- Shows coverage gaps

**4. ROUTE VISUALIZATION**
- Draw line from adjuster to their assigned claims
- Shows optimized route order (1, 2, 3...)
- Estimated travel time between points
- Total distance for the day

**5. REAL-TIME UPDATES**
- Adjuster moves = marker moves
- Adjuster checks in = marker changes color
- New claim filed = new marker appears
- Claim completed = marker turns green

## **💡 SMART ASSIGNMENT LOGIC - HR'S SECRET WEAPON**

### **When HR Assigns a Claim, System Suggests:**

**1. PROXIMITY SCORING**
```
Calculate distance between adjuster and claim
Closest adjuster gets highest score
```

**2. WORKLOAD SCORING**
```
Adjuster with 2 claims = High availability
Adjuster with 8 claims = Low availability
System suggests lighter workload adjuster
```

**3. EXPERTISE MATCHING**
```
Fire damage claim → Suggest fire specialist
Water damage → Suggest water damage expert
Theft → Suggest theft investigator
```

**4. AVAILABILITY CHECK**
```
✅ Active and working
✅ Not on leave
✅ Not sick
✅ Has capacity (under max claims)
❌ On vacation - skip
❌ Overloaded - warning
```

**5. TERRITORY MATCH**
```
Claim in North Zone → Assign North adjuster
Reduces travel time and costs
```

**6. AUTO-SUGGESTION ALGORITHM**
```
System ranks all adjusters 1-10
Shows top 3 recommendations
HR can override if needed
```
